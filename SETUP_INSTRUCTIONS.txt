===========================================
SUPABASE + PRISMA SETUP INSTRUCTIONS
===========================================

STEP 1: Get Supabase Connection String
----------------------------------------
1. Go to https://app.supabase.com
2. Select your project
3. Settings > Database
4. Copy "Connection string" (Connection pooling mode)
5. Format: postgresql://postgres:[PASSWORD]@[PROJECT-REF].supabase.co:6543/postgres?pgbouncer=true

STEP 2: Create .env file
-------------------------
Create .env in project root with:

DATABASE_URL="postgresql://postgres:[YOUR-PASSWORD]@[PROJECT-REF].supabase.co:6543/postgres?pgbouncer=true"
DIRECT_URL="postgresql://postgres:[YOUR-PASSWORD]@[PROJECT-REF].supabase.co:5432/postgres"

Replace:
- [YOUR-PASSWORD] = Your Supabase database password
- [PROJECT-REF] = Your Supabase project reference ID

STEP 3: Pull Schema from Supabase (If tables exist)
-----------------------------------------------------
npm run prisma:pull

This will sync your Prisma schema with existing Supabase tables.

STEP 4: Generate Prisma Client
-------------------------------
npm run prisma:generate

This runs automatically on npm install.

STEP 5: Verify Setup
---------------------
npm run prisma:studio

This opens Prisma Studio to view your database.

===========================================
DONE! Your Prisma + Supabase setup is complete.
===========================================

See SUPABASE_SETUP.md for detailed documentation.
